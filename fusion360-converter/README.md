# Fusion360Converter

Fusion360Converter is an early-stage Rust project intended to inspect Fusion archives and support reviewed, operation-by-operation migration to CAD applications. These capabilities are not implemented yet.

Build and run the current starter binary with `cargo run`; run its checks with `cargo check` and `cargo test`. See [implementation status](docs/implementation_status.md) and [AGENTS.md](AGENTS.md) for the planned work and constraints.
